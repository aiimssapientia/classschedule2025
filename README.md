# 🩺 AIIMS Bhubaneswar MBBS Batch 2025 Class Calendar (3rd Semester)

An editorial, responsive, interactive weekly timetable and academic calendar web application for **AIIMS Bhubaneswar MBBS Batch 2025 (3rd Semester, August – December 2026)**.

Built with pure **HTML5, Modern CSS3, and Vanilla JavaScript (ES6+)** with zero external frameworks or heavy dependencies. Fast, mobile-first, offline-capable, and completely isolated from Batch 2023.

## ✨ Web App Features

- **Triple View Engine (Fully Mobile Optimized)**:
  - **📱 Agenda View**: Touch-optimized vertical card stream with sticky day headers, colored subject badges, faculty info, and timing pills.
  - **🗓️ 7-Day Timetable Grid**: Full 8:00 AM to 6:00 PM timetable matrix with sticky time/day headers, touch-friendly day jump strip (Mon–Sun), and horizontal swipe.
  - **⚡ Both View (Split/Combined)**: View both the 7-day grid and daily agenda stream simultaneously on mobile or desktop.
- **🔍 Instant Live Search & Filter**:
  - Filter by Department (8 departments), Type (Theory vs Practical), or search by topic, faculty, or room.
- **📅 Interactive Month Calendar Modal**:
  - Full monthly overview with dot indicators on dates with classes.
- **🔔 Class Notification & Reminders**:
  - Configurable reminder alerts before each class with sound chime and browser notifications.
- **📲 1-Click Phone Calendar Sync (`.ics`)**:
  - Pre-generated standard RFC 5545 `.ics` file (`batch2025.ics`).
  - Import classes with 15-minute alarms into **Google Calendar, Apple Calendar, or Microsoft Outlook**.
