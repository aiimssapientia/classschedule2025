Publish to GitHub Pages in 3 Steps

This entire project is a static web app built with zero dependencies. You can host it for free on GitHub Pages with your own live link:

Step 1: Create a GitHub Repository

Go to github.com/new and create a public repository named batch2025-calendar.

Step 2: Push code from your terminal
cd "c:\Users\MOULIK GORAI\Desktop\website\batch2025-calendar" git init git add . git commit -m "AIIMS Bhubaneswar MBBS Batch 2025 Class Calendar" git branch -M main git remote add origin https://github.com/<YOUR-USERNAME>/batch2025-calendar.git git push -u origin main
Step 3: Enable GitHub Pages

In your GitHub repository, open Settings > Pages > Select branch main and folder /(root) > Click Save.

Your calendar will be live at:
https://<YOUR-USERNAME>.github.io/batch2025-calendar/
